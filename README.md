# IMG Cursos — Site Institucional

Protótipo de um novo site institucional para a **IMG Cursos**, escola técnica profissionalizante localizada em Itabuna, Bahia.

O projeto apresenta os cursos da instituição, informações para matrícula, canais de atendimento, localização e acessos aos portais acadêmicos. A interface foi desenvolvida para funcionar em computadores, tablets e celulares.

## Visualização

[Acessar o site](https://jocax71.github.io/Teste-IMGCursos/)

## Recursos

- Apresentação institucional da IMG Cursos
- Cursos técnicos e profissionalizantes em destaque
- Detalhes e contato de interesse para cada curso
- Integração com o WhatsApp para atendimento e matrícula
- Links para os portais do aluno e do professor
- Telefones, e-mail, endereço e redes sociais
- Mapa com a localização da instituição
- Navegação responsiva para dispositivos móveis
- Estrutura semântica e recursos básicos de acessibilidade

## Cursos apresentados

- Técnico em Eletrotécnica
- Técnico em Segurança do Trabalho
- RD — Redes de Distribuição
- Eletricidade em Atividades Comerciais

## Tecnologias

- HTML5
- CSS3
- JavaScript

O projeto não utiliza frameworks ou dependências externas para funcionar.

## Estrutura do projeto

```text
Teste-IMGCursos/
├── assets/          # Logo e imagens utilizadas no site
├── index.html       # Estrutura e conteúdo da página
├── style.css        # Estilos gerais e responsividade
├── sections.css     # Estilos das seções internas
└── script.js        # Cursos, links e interações
```
